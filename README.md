# openedx-course-payments

Django plugin for the Open edX LMS: the Open edX side of Campus.

Courses are sold and paid for in the Campus CMS (`campus-cms`): it runs the
Stripe checkout and, once a payment is confirmed, enrolls the buyer in the
course's `verified` mode through the LMS enrollment API. This plugin makes the
LMS go along with that:

- only paying learners get into a course;
- course "About" pages live on the public site.

(It used to run the Stripe checkout itself, hence the name; that moved to the
CMS, which now keeps the orders.)

## Only paying learners get in

An Open edX Filters step on `org.openedx.learning.course.enrollment.started.v1`
(`filters.RequirePaidEnrollment`) runs inside every `CourseEnrollment.enroll()`
and rejects any enrollment that isn't `verified`. Learners can't request
`verified` themselves, so the only way in is the CMS after a payment. Staff and
the course team (any course role, e.g. the authors) are let through to preview
the course. The filter is configured with `fail_silently: False`, so a broken
step blocks enrollments instead of letting them through.

Existing enrollments are not touched. To allow free enrollments again, set
`COURSE_PAYMENTS_REQUIRE_PAID_ENROLLMENT = False`.

## Public site integration

With `COURSE_PAYMENTS_PUBLIC_SITE_URL` set, two Open edX Filters steps send
course "About" pages to the public site (`{site}/cursos/{course_id}`):

- `org.openedx.learning.course_about.render.started.v1` → redirect
- `org.openedx.learning.course_about.page.url.requested.v1` → links generated by the LMS

The Tutor plugin also whitelists the site for login `?next=` / logout `?redirect_url=`.

## Local development (Tutor)

The directory name must start with `openedx-` so Tutor installs it automatically.

```bash
tutor mounts add /path/to/openedx-course-payments
tutor dev stop                   # with 8 GB of RAM webpack runs out of memory otherwise
tutor images build openedx-dev
tutor dev start -d
tutor dev exec lms ./manage.py lms migrate course_payments
```

Settings are injected by the single-file Tutor plugin in `tutor/coursepayments.py`:

```bash
ln -s "$PWD/tutor/coursepayments.py" "$(tutor plugins printroot)/coursepayments.py"
tutor plugins enable coursepayments
tutor config save --set COURSE_PAYMENTS_PUBLIC_SITE_URL=http://www.local.openedx.io:3000
tutor dev restart lms
```

## Tests

```bash
tutor dev exec lms bash -c "cd /openedx/edx-platform && pytest -c setup.cfg --rootdir=. --ds=lms.envs.tutor.test -p no:cacheprovider /mnt/openedx-course-payments/course_payments/tests"
```

## Settings

| Setting | Default |
|---|---|
| `COURSE_PAYMENTS_PUBLIC_SITE_URL` | `""` (filters disabled) |
| `COURSE_PAYMENTS_REQUIRE_PAID_ENROLLMENT` | `True` |
